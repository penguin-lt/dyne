# Dyne - Probably Inspired Scriptures

An academic, historical-critical translation project in ordinary modern English.

## The code

The project's only rule document is
[rulesforanacademicbible.md](rulesforanacademicbible.md). It states every rule,
what it forbids, and how a failure is detected. Cite a Part by its title, not its
number. Numbers drift, titles do not.

One file, one order, no duplication.
